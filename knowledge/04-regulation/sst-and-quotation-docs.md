# SST threshold and quotation/pro-forma rules

Related: [[e-invoice-myinvois]], [[pdpa-malaysia]]

- Registration threshold: taxable turnover above RM500,000 in 12 months (sales tax for manufacturers; service tax generally, some service categories differ). Online via MySST; returns bi-monthly. Service tax 8% for most categories (2024 rise).
- Voluntary registration possible below threshold.
- Rule specific to quotations / pro-forma documents: **none found** in any source. Assume a quotation is a commercial document with no statutory form. If SST-registered, state whether quoted prices are SST-inclusive (practice, unverified).
- Note ILMU API prices also carry 8% SST from 1 Jun 2026 ([[adr-ilmu-api]]).
