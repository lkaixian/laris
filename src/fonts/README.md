PDF fonts for Chinese and Tamil (Latin and Malay use Ubuntu from web/public/fonts). Both are SIL Open Font License 1.1, from github.com/google/fonts (ofl/notosanssc, ofl/notosanstamil), instanced to Regular (wght 400) with fontTools.
- NotoSansSC-Regular.ttf, 2.2 MB: subset to Latin, punctuation and the 6,763 GB2312 hanzi (Simplified Chinese, everyday names). Rarer characters print as a blank box, never an error. The full font is 17 MB.
- NotoSansTamil-Regular.ttf, 81 KB: whole font.
